# Devpost submission checklist

- [ ] Project title + tagline (under 60 chars)
- [ ] Devpost writeup filled in (the README sections mirror the form)
- [ ] Demo video (usually under 3 min, public YouTube/Vimeo link)
- [ ] Repo made public before deadline
- [ ] Screenshots / cover image (16:9)
- [ ] Built-with tags (languages, frameworks, APIs)
- [ ] Tracks / prize categories picked
- [ ] Team members added on Devpost
- [ ] Live demo link works logged out
- [ ] No secrets committed (`git log -p | grep -i key` sanity check)
